# 🧪 Task 3 — Storage Read/Write Speed

## Background (microSD & Pi generations)

Raspberry Pi boards boot from a **microSD card** (unless you use USB/ NVMe setups on supported models). Pi 4 SD throughput depends on card **UHS / class** rating and filesystem; Pi 5 adds **SDR104** high-speed mode via the RP1 I/O controller ([Pi 5 overview](https://www.raspberrypi.com/products/raspberry-pi-5/)), often roughly **doubling peak SD performance** vs Pi 4 in vendor documentation.

The `dd` test measures **sequential** read/write to the card holding `testfile.bin`. Results in MB/s are **not** CPU bitness limited — they reflect storage hardware. Always state **Pi model + SD card type** in your report.

### 1️⃣ Write test:
```bash
dd if=/dev/zero of=testfile.bin bs=100M count=1 oflag=direct
```

### 2️⃣ Read test:
```bash
dd if=testfile.bin of=/dev/null bs=100M count=1 iflag=direct
```

### 3️⃣ Record:
- Write speed
- Read speed
