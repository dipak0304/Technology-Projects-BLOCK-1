## Disassembly vs source

The compiled `main` contains prologue/epilogue code (stack setup, branch to `printf`), load/store of locals `x` and `y`, and a call to the C library. Compared to the tiny assembly add program, you see more instructions because the compiler must follow the ABI, align the stack, and link with `printf`. A few lines in `main.disasm.head.txt` will correspond to setting `x = 5` and computing `y = x + 3` before the call to `printf`.
