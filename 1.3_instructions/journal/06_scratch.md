# Scratch — reflection

Scratch uses **blocks** instead of text: set variable `x` to 5, change `x` by 3, then **say** the value (8). That mirrors the same sequence as C/Python (store, add, display) but hides syntax and memory details. Scratch is interpreted in the browser/runtime on each click on the green flag; it is ideal for seeing control flow and variables before dealing with compilers and terminals.

Evidence: export project or screenshot to `scratch/` when completed on the Pi.
