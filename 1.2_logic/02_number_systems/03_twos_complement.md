## Two's Complement
**Find the two's complement of the binary number:**
   - 101010 → invert: **010101**, add 1: **010110**
   - 110011 → invert: **001100**, add 1: **001101**
   - 1001 → invert: **0110**, add 1: **0111**

*(Using the same bit width as the given number: flip every bit, then add 1.)*
