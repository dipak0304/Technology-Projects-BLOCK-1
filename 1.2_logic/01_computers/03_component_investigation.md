# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU | Executes program instructions; performs arithmetic, logic, and control operations. | Example: quad-core x86-64, ~3.0 GHz base clock (record your chip model from the label). |
| RAM | Stores data and instructions the CPU needs while the system is running; volatile, fast access. | Example: 8 GB DDR4, 2666 MHz, dual-channel (match your modules). |
| Storage | Retains operating system, applications, and files when power is off. | Example: 256 GB SATA SSD + 1 TB HDD (record capacity and interface). |
| Motherboard | Connects CPU, RAM, storage, and expansion; provides power distribution and I/O. | Example: ATX form factor, chipset and socket type for your CPU. |
| Power Supply | Converts mains AC to regulated DC voltages (+12 V, +5 V, +3.3 V) for components. | Example: 500 W 80 Plus, active PFC (read label on your PSU). |
| Cooling | Removes heat from CPU and case to prevent thermal throttling or shutdown. | Example: aluminium heatsink + 120 mm fan; optional rear exhaust fan. |
