# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.

Hardware is the physical equipment that makes up a computer system. It includes components you can touch, such as the processor (CPU), memory chips (RAM), storage drives, motherboard, power supply, cooling fans, and input/output devices like keyboards and screens. Hardware provides the electrical circuits and mechanical structures that store and move data. Without hardware, there is no machine to run programs on; it defines the speed, capacity, and connectivity limits of what the system can do.

---

## Explain Software
Write **at least 50 words** explaining what software is.

Software is a collection of instructions and data that tell hardware what to do. It ranges from the operating system (which manages files, memory, and devices) to applications such as browsers and games, and down to firmware and drivers that control specific chips. Software is stored on media such as a hard drive or microSD card and loaded into memory when needed. Unlike hardware, software can be copied, updated, and replaced without changing the physical machine, though it always depends on compatible hardware to execute.

---

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

Hardware and software work together in layers: software sends commands that the CPU executes as machine instructions, which in turn switch transistors and move data through buses to RAM, storage, and peripherals. The operating system mediates access so programs do not conflict. When you press a key, hardware generates a signal, firmware or drivers translate it, and application software decides how to respond. Performance, reliability, and features emerge from this partnership—software cannot run without hardware, and hardware is largely useless without software to give it purpose.
